# AI产业链智能监控平台 — 集成方案

## 一、项目定位

**一句话**：把分散在10+个平台的AI产业链数据（股价、库存、研报、龙虎榜、融资融券、新闻）聚合到一个网站，用AI自动分析关联、生成洞察，替代人工翻消息。

**核心价值**：
- 消息聚合：不再逐个翻东方财富/新浪/SHFE，一个页面看完
- AI关联分析：自动识别"某事件→影响哪些标的→传导路径"
- 实时信号：异常变动秒级推送，不等新闻

## 三、技术选型与理由

| 层级 | 技术 | 理由 |
|------|------|------|
| **后端** | Flask + Gunicorn | 已有经验(SLB)，轻量，生态成熟 |
| **数据库** | SQLite (已有) | 14只股票60天数据<50MB，无需MySQL |
| **前端** | TailwindCSS CDN + Alpine.js | 无需构建工具，写在HTML里直接用 |
| **图表** | ECharts | 国产，金融K线图原生支持，中文文档 |
| **AI引擎** | MiMo Proxy (已有 :3001) | 免费，延迟低，中文能力强 |
| **实时推送** | SSE (Server-Sent Events) | 比WebSocket简单，Flask原生支持 |
| **反代** | Caddy (已有) | 自动HTTPS，一行配置 |
| **任务调度** | APScheduler (已有) | 已在ai-monitor中使用 |

**资源占用预估**：
- Flask: ~100MB RAM
- 数据采集: ~50MB RAM
- AI调用: 每日~50次，MiMo免费
- 存储: SQLite ~50MB + 日志 ~100MB
- **总计: ~200MB RAM，2核VPS完全够用**

## 六、AI分析引擎设计

### 6.1 分析流程

```
原始消息 → 分类打标 → 影响评估 → 关联匹配 → 生成报告
    │          │          │          │          │
    ▼          ▼          ▼          ▼          ▼
 新闻/研报   行业/个股   利好/利空   传导链    一句话摘要
 /公告       /宏观       /中性      路径      +操作建议
```

### 6.2 AI Prompt 设计

**消息摘要Prompt**：
```
你是AI产业链分析师。请对以下消息进行分析：
1. 一句话摘要（30字内）
2. 影响判断：利好/利空/中性
3. 受影响标的（从监控列表中选）
4. 传导逻辑（一句话）
5. 置信度：高/中/低

监控列表：中际旭创、新易盛、工业富联、浪潮信息、深南电路、
兴森科技、英维克、长电科技、通富微电、沃尔核材、锡业股份、
紫金矿业、寒武纪、海光信息

消息：{message}
```

**每日综合分析Prompt**：
```
你是AI产业链首席分析师。根据今日数据生成分析报告：

价格异动：{stock_signals}
投行数据：{institutional_signals}
库存数据：{inventory_data}
日历事件：{calendar_events}

要求：
1. 整体市场情绪判断（偏多/中性/偏空）
2. 板块轮动分析
3. 值得关注的机会（2-3个）
4. 风险提示（1-2个）
5. 明日关注点
```

### 6.3 AI调用策略

| 场景 | 频率 | Token消耗 | 模型 |
|------|------|-----------|------|
| 消息摘要 | 每条新闻 | ~200 tokens | MiMo |
| 个股分析 | 每日收盘 | ~500 tokens | MiMo |
| 综合报告 | 每日收盘 | ~1500 tokens | MiMo |
| 关联图谱 | 事件驱动 | ~800 tokens | MiMo |
| **日均总计** | ~50次 | ~15K tokens | 免费 |

### 7.2 关联规则

当事件发生时，自动匹配：
1. **直接关联**：消息提到的标的
2. **产业链关联**：上下游标的
3. **板块关联**：同板块标的
4. **历史关联**：历史上同涨同跌的标的

## 十一、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 东方财富API限速 | 采集失败 | 多源备份(腾讯/新浪)，重试+缓存 |
| MiMo代理过期 | AI分析中断 | 备用：本地小模型/其他免费API |
| VPS资源不足 | 页面卡顿 | 静态化缓存，AI结果缓存24h |
| 数据源API变更 | 采集器失效 | 模块化设计，单个替换不影响全局 |
| SHFE WAF拦截 | 库存数据缺失 | 手动录入 + 新闻提取 |
